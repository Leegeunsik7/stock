# v5.0.0 — 단계적·가역적 점화 아키텍처 청사진 (Phased Ignition)

> **상태**: 설계 명세 (Blueprint) — 구현 코드 없음 · 점화 행위 아님
> **기준**: v4.10.0 (1036 테스트, 그림자 파이프 + 단방향 밸브) 위
> **본질**: 실제 자본이 최초로 와이어를 타는 단계. '이진 스위치'가 아닌 **점진 압력 + 즉시 후퇴** 가역 파이프.

---

## 0. ⚠️ 가장 중요한 정직 경계 (먼저 읽을 것)

이 문서는 **설계**일 뿐 점화가 아니다. 그러나 v5.0.0 은 이전 모든 마일스톤과 **질적으로 다르다**:

| 사실 | 함의 |
|------|------|
| **실 자본이 와이어를 탄다** | 지금까지 전부 드라이런/그림자. v5.0.0 은 실제 키움 계좌·실제 돈·실제 체결. |
| **라이브 왕복은 1036 테스트가 한 번도 검증 못 한 영역** | 테스트는 장애 주입 가짜로만 라이브 경로를 친다. 실 키움 프록시→거래소→체결 왕복은 CI 로 검증 불가 → **첫 실주문이 가장 위험하고 가장 커버리지 낮은 순간.** |
| **체결은 되돌릴 수 없다** | 미래 주문은 동결할 수 있으나, 이미 체결된 주문은 취소가 아니다(반대매매만 가능, 손실 확정 가능). |
| **밸브가 약화된다** | S21 #2 의 `static readonly` 절대 하드블록 → 서명 게이트형 **런타임 개방 가능** 밸브. 이것이 넘는 문턱이며, 본 설계의 핵심 위험원이다. |
| **이것은 지휘관 본인의 리테일 자본·결정** | 설계의 책무는 위험 *제거*가 아니라 위험을 *최소화·한정·전방가역(언제든 드라이런 후퇴)* 으로 만드는 것. 점화 방아쇠는 인간만 당긴다. |

> **인식적 겸손(S21 §6 계승)**: 1036 테스트와 카오스 통과는 *알려진* 장애 모드의 방어를 입증할 뿐, 라이브 시장·브로커의 *미지* 거동에 대한 절대 안전이 아니다. 단계적 점화는 그 미지를 **작게·짧게·가역적으로** 만나기 위한 장치다.

## 1. 3단계 가역 파이프라인

```
 부팅 ──[항상 드라이런/그림자]──> Stage 0 (Locked, 기본)
        │ 인간 암호 서명 토큰 주입
        ▼
 Stage 1: 1주 프로브 ──(1체결 즉시 자동 재잠금)──> Locked + 실측 상수 박제
        │ 인간 검토·재서명
        ▼
 Stage 2: 시간상자 개방 ──(30분 경과 | 3σ | 디싱크 1주 → 즉시 EmergencyFreeze + 드라이런 리버트)
        │ 인간 검토·재서명
        ▼
 Stage 3: 마스터 골드 (제한 운용) ──(언제든 후퇴 가능, 부팅 시 다시 Locked)
```

| 단계 | 목적 | 제어 | 자동 후퇴 |
|------|------|------|-----------|
| **S1 단일주 프로브** | 실 왕복 지연·실물 체결 슬리피지 Z 첫 실측 | 단 1회·1주 발주만 허용 | 1체결 즉시 밸브 자동 재잠금(`Armed→Locked`) → 인간 검토 대기 |
| **S2 시간상자** | 충격 적은 시간대(예: 11:00~11:30)만 한시 개방 | 창 진입 시 서명, 창 만료 시 자동 잠금 | 30분 경과 OR 3σ 경보 1회 OR 디싱크 1주 → `EmergencyFreeze` + 드라이런 강제 리버트 |
| **S3 마스터 골드** | Fail-Closed 부팅 최종 결속 | 부팅은 무조건 Locked, 운영 중 서명으로만 제한 개방 | 모든 카오스/디싱크/하트비트 유실 트리거 상시 활성 |

## 2. 핵심 메커니즘: 서명 게이트형 런타임 밸브 (`IgnitionLock`)

S21 #2 밸브(`ShadowMetricsBridge.BlockPhysicalOrder` = `static readonly true`)는 런타임에 못 연다.
v5.0.0 은 이를 **`IgnitionLock` 런타임 상태기계**로 교체한다 — 단, 안전 기본값은 여전히 Locked.

```
IgnitionLock (신규 — 인간 매개 상태기계)
 ├─ enum IgnitionStage { Locked, SingleShareProbe, TimeBoxed }   // 기본 Locked
 ├─ Stage         : 현재 단계 (volatile, 락-프리 독출)
 ├─ Arm(stage, signedToken, window?) : 서명 검증 통과 시에만 단계 진입
 ├─ Lock(reason)  : 즉시 잠금(자동 후퇴·인간 취소·트리거)
 ├─ AllowPhysical(intent) → bool : 현재 단계·창·잔여 프로브 수에 따라 물리 발주 허용 판정
 └─ 감사 원장 : 모든 Arm/Lock/Allow 를 서명·시각과 함께 박제
```

밸브 판정은 `ShadowMetricsBridge`/집행 경로 최하단에서:
```
Place(intent):
   if (!ignitionLock.AllowPhysical(intent))  → 차단(그림자 ack)        // 기본 경로
   else                                       → 실 브로커 위임 + 프로브 카운트 차감/창 검사
```
- `AllowPhysical` 은 **다중 조건 AND**: 단계≠Locked AND (S1이면 잔여프로브>0) AND (S2면 창 안 AND 미동결) AND attestation Normal AND 하트비트 생존.
- 어느 하나라도 거짓이면 차단. **기본 Locked + 모든 게이트 AND** = fail-closed 유지.

## 3. 자동 후퇴 트리거 (Reversion — 인간 개입 없이 즉시)

기존 안전 부품을 재사용해 **즉시·자율** 후퇴를 배선한다(전부 이미 검증됨):

| 트리거 | 출처(기존) | 동작 |
|--------|-----------|------|
| 슬리피지 3σ 경보 | `SlippageSentinel.AlertTriggered` (실측 체결) | `IgnitionLock.Lock` + `OrderAttestationService.ForceFreeze` |
| 원장 디싱크 1주 | `AlgoExecutionGate` 가드3 / `MultiAccountMesh` | 즉시 EmergencyFreeze + 드라이런 리버트 |
| 하트비트 유실 | `KiwoomBridgeClient.ProxyLost` | 밸브 잠금 + 동결(파이프 끊김 = 발주 불가) |
| 시간상자 만료 | 결정론 시계/타이머 | 창 종료 → 자동 Lock |
| 캡 연속 위반 | `AdaptiveExecutionTuner` (S17) | 안전 동결 → 밸브 잠금 |
| 부팅 | `BootIntegrityChecker` (S18) | 항상 Locked + 이전 동결 복원 |

> 핵심: 점화는 **인간만** 켤 수 있고, 후퇴는 **기계가 자율로** 즉시 한다(비대칭 안전).

## 4. 인간 매개형 이그니션 서명 락

- 부팅 시 무조건 `Stage = Locked`. 어떤 플래그·설정 파일도 자동 개방하지 못한다.
- 개방은 관제탑 UI 에서 지휘관이 **암호화 서명 토큰**을 주입할 때만. 토큰은 DPAPI 보호(기존 `db.GetSecret` 인프라 재사용) + 단계별 별도 서명.
- 패턴 재사용: `PromotionGateway` 의 서명 검증기 + `OrderAttestationService.ManualRelease` 의 인간 서명 도어락.
- **단일 사용 / 자동 만료**: S1 서명은 1주 1회만, S2 서명은 창 1회만. 재개방은 재서명 필수.
- 모든 점화/후퇴는 감사 원장(서명·시각·실측치)에 박제 → 사후 추적.

## 5. 부팅 Fail-Closed 최종 결속

- `Program.cs`/`BlazorHomeForm` 부팅 경로: `IgnitionLock` 은 항상 `Locked` 로 생성.
- `BootIntegrityChecker`(S18)가 이전 세션 동결을 복원하면 점화는 원천 불가.
- `--headless`/자동 실행 모드에서도 **자율 점화 영구 금지** — 점화는 대화형 UI 서명에만.

## 6. 테스트 가능 경계 (결정론) vs 미달 영역 (라이브)

| 검증 가능 (결정론·CI) | 검증 불가 (라이브·통합 전용) |
|----------------------|------------------------------|
| `IgnitionLock` 상태기계 전이·기본 Locked·AND 게이트 | 실 키움 프록시 왕복 지연·실물 체결 |
| 서명 검증·단일사용·자동만료 | 실거래소 체결 슬리피지·부분체결·거부 코드 |
| 자동 후퇴 트리거(3σ/디싱크/ProxyLost/만료) → Lock+Freeze | 장중 시장 충격·호가 공백·VI 발동 |
| 시간상자 경계(가상 시계)·프로브 카운트 차감 | 네트워크·증권사 서버 장애 실거동 |
| 부팅 항상 Locked·헤드리스 자율점화 금지 | — |

> 좌측은 ~20+ 단위 테스트로 박제 가능. 우측은 **본질적으로 CI 불가** — 그래서 S1(1주)이 최소·가역으로 그 미지를 처음 만나는 장치다.

## 7. 정직 경계 (Honest Boundaries)

1. **청사진 ≠ 점화.** 본 문서는 설계다. 구현·서명·실주문은 각각 별개의 의도적·인간 매개 행위다.
2. **밸브 약화는 명시적 문턱이다.** `static readonly` 하드블록 → 런타임 서명 게이트. 설계는 이를 최대한 안전화하나, "절대 못 엶"에서 "서명하면 엶"으로의 이행임을 숨기지 않는다.
3. **첫 실주문은 최저 커버리지·최고 위험.** 라이브 왕복은 테스트가 못 친 유일 영역. S1 1주는 이 사실에 대한 직접적 대응이다.
4. **체결은 비가역.** 전방 후퇴(미래 발주 차단)는 항상 가능하나, 체결된 1주는 되돌릴 수 없다.
5. **이것은 지휘관의 자본·판단.** 설계는 위험을 최소·한정·가역으로 만들 뿐, 제거하지 않는다.
