## 2. 부팅 무결성 5축 스캔 (`GoldenMasterBootSentinel`)

부팅 시 리플렉션 정적 산술 스캔으로 5대 무결성 축을 검사하고, **단 1개라도 결함이면 fail-closed**(`AllPassed=false`)로 판정한다. 판정 커널 `Evaluate(ReadOnlySpan<GoldenMasterCheck>)`는 unmanaged 체크 스팬을 stackalloc으로 순회 → **δ=0(힙 0)·결정론**.

| # | 축 (`GmCheckId`) | 통과 조건 | 판독 방식 |
|---|---|---|---|
| ① | `RclZeroEngineRef` | RCL이 호스트/엔진 어셈블리 역참조 0 | `Assembly.GetReferencedAssemblies()` |
| ② | `HostCoupledWithinRatchet` | `coupled(40) ≤ RatchetCeiling(40)` | `PureShellFitnessSentinel.Scan` |
| ③ | `LiveArmedFalse` | 부팅 시 카나리 미무장 | `CanaryHealthSentinel.IsArmed == false` |
| ④ | `DualKeyAbsent` | 물리 이중 키 미연결(안전 기본) | 프로브 |
| ⑤ | `VaultSealed` | API 금고 DPAPI 봉인(평문 시크릿 0) | 프로브(strict=DPAPI 검사) |

- **판정 산술**: `AllPassed = (total > 0) ∧ (passed == total)`. 빈 스팬·부분 통과 → **거부**(우발적 무장 차단).
- **v12.0.0 실측**: 5/5 PASS → `AllPassed=true`. (`Phase98GoldenMasterTests`)
- **strict 골든마스터 빌드**: `!AllPassed` → **부팅 거부**. 개발/CI 빌드는 `[GoldenMaster]` 로그만 남기고 진행(fail-safe). 배선: `BlazorHomeForm` sp 생성 직후.

## 3. Release 빌드 δ=0 (무할당 핫패스) 규격

핫패스 힙 할당 0은 **Release 빌드가 판정 표준**이다. Debug JIT은 미최적화로 소량(예: 24B) 할당을 삽입하나 Release는 최적화로 0이 된다 — δ=0 테스트는 Release로만 유의미하다.

| 엔진 | δ=0 핫패스 | 검증 테스트 |
|---|---|---|
| `CanaryHealthSentinel` | `TryAuthorize`/`Kill`(Interlocked/CAS·고정버퍼 ZeroMemory) | `Phase114CanarySentinelTests.TryAuthorize_ZeroAllocation` |
| `HardwareInterruptSpinLock` | `PollOnce`(SpinWait 루프) | `Phase95HardwareKillSwitchConcurrencyTests` |
| `LockFreeSignalDemuxer` | `Signal`(Interlocked.Or 병합) | `Phase96SignalDemuxerConcurrencyTests` |
| `ZeroAllocDualBrokerCoalescer` | `Publish`/`Drain`(사전할당 링·Span) | `Phase97DualBrokerCoalescerConcurrencyTests` |
| `LongRunningMemoryGcSentinel` | `ShouldThrottle`(Volatile 판독) | `Phase97...GcSentinel_ShouldThrottle_HotPath_ZeroAllocation` |
| `ZeroAllocRowStreamMapper` | `Project<T:unmanaged>(Span)` | `Phase98GoldenMasterConcurrencyTests.Mapper_Project_HotPath_ZeroAllocation` |
| `GoldenMasterBootSentinel` | `Evaluate`(stackalloc 스팬) | `Phase98...BootSentinel_Evaluate_ZeroAllocation` |

- **측정 방식**: 전용 스레드 + 300k 워밍업 후 `GC.GetAllocatedBytesForCurrentThread()` 로 100k 구간 측정 → **0 Byte** 단언.
- **격리**: 타이밍/δ=0/멀티스레드 테스트는 `[Collection("ConcurrencyStress")]`로 직렬화(병렬 플래키 방지).

## 4. liveArmed:false 안전 사슬 (부팅 → 인가 → 킬스위치 → 중독)

```
콜드 부팅        카나리 인가 게이트         하드웨어 킬스위치         메모리 중독
[미무장]  ──▶   [물리 이중 키만 무장]  ──▶  [USB/COM/Pipe/MMF]  ──▶  [API Secret 0x00]
IsArmed=F      Arm(cap,valve∧liveArm)     Signal→sticky Disarm     PoisonedSecretBuffer
               0.1% cap·초과→0ms Kill      +CancellationToken 취소   중독→재참조 ODE
```

1. **부팅**: `GoldenMasterBootSentinel` 5축 PASS. 카나리 미무장(`liveArmed:false`).
2. **무장**: `CanaryHealthSentinel.Arm(cap, valveWired, liveArmingWired)` — **둘 다 true**일 때만 성립. 하나라도 결여 → 무장 실패·`TryAuthorize` 항상 0(**100% Veto**).
3. **0.1% 마이크로 캡**: `cap = 총자산 × 0.001`. 누적 인가 ≤ cap. **1원 초과 → 0ms 원자 Kill**(BudgetBreach) + 발주 토큰 `ZeroMemory`(0x00) + sticky.
4. **하드웨어 킬스위치**: `HardwareKillSwitchBridge.Signal` → sticky Disarm + `CancellationTokenSource.Cancel`(진행 발주 토큰 취소) + `Killed` 이벤트 → 카나리 Kill + `VolatileMemoryPurger.PurgeAll`.
5. **메모리 중독**: `PoisonedSecretBuffer.PurgeAndPoison` — 소거(0x00) + 중독 표식. 이후 `ReadByte`/`CopyTo`/`AsSpan` 접근 시 **`ObjectDisposedException`**(뒤늦은 async API 키 재사용 차단).
6. **재무장**: `TryRearm(valveWired ∧ liveArmingWired)` — **물리 이중 키만**. 소프트웨어 단독 복구 불가(sticky).

> **v12.0.1 실증**: `Stage1CanaryIgnitionSimulationTests` — 콜드부팅 자세·키 미결속 5,000발주 100% Veto·0.1% 미세무장·1원 초과 0ms Kill+토큰0x00+Secret 중독·하드웨어 킬 주입·동시 발주 cap 누출 0.

## 5. 시스템 포렌식 체크리스트 (신규 엔지니어용 · 부팅 → 긴급 Disarm)

- [ ] 콘솔 단독 모드 여부: `appsettings.json` → `Edge.Enabled` (false=로컬 폴백).

### 5-2. 무장(라이브 발주 개통) 판독

- [ ] `Arm` 성공 시 `CapRaw == 총자산 × 0.001`(Stage-1 = 0.1%).
- [ ] 한 키 결여 시 `Arm` 실패 + `TryAuthorize` 전량 0 확인(100% Veto).

### 5-3. 정상 운용 중 관측(SRE)
- [ ] 발주 인가: `Authorized`/`Blocked` 카운터 추이(비정상 급증=경보).
- [ ] 텔레메트리 이상: `NoteAnomaly`(429/지연/슬리피지) → 자동 Kill 여부.
- [ ] GC 압력: `LongRunningMemoryGcSentinel.ShouldThrottle`(장기 체공 누수 감속).

### 5-4. 긴급 Disarm 절차
- [ ] **소프트웨어**: `CanaryHealthSentinel.Kill(reason)` — 즉시 armed=0 + 토큰 0x00 + sticky.
- [ ] **하드웨어**: 물리 킬스위치 버튼 → `HardwareKillSwitchBridge.Signal` — 전역 Disarm + 토큰 취소 + Secret 중독.

- [ ] **복구**: 물리 이중 키 재결속 후 `TryRearm(true, true)` — 소프트웨어 단독 복구 불가.

### 5-5. 사후 감사(포렌식)
