# 회사 로고(브랜드 마크) 넣는 곳

앱의 회사 마크를 실제 로고 이미지로 바꾸려면 이 폴더에 이미지를 저장하세요.

## 저장할 파일
- `ang-logo.png` — **흰색 버전 로고**(사이드바·로그인 배경이 어두워서 흰색이 잘 보임). 지휘관이 주신 2장 중 **흰색 이미지**를 이 이름으로 저장.
- (선택) `ang-logo-color.png` — 파란색 버전(밝은 배경용).


## 저장한 뒤
저장하셨다고 알려주시면, 사이드바 마크와 로그인 화면 로고를 이 이미지(`<img src="brand/ang-logo.png">`)로 즉시 배선하겠습니다.
