# 런타임 도그푸딩 체크리스트 — Season 8·9 (v3.58 → v3.65)

> **목적**: 단위 테스트로는 검증 못 하는 **UI 렌더 · 실시간 시세 · LLM · 비동기 상태**를 실제 앱에서 점검한다.
> 빌드+단위테스트(486건)는 ✅ 검증됨. 아래 항목은 **런타임(사용자 검증)** 경계다.
> 공통 불변식: **게이팅** — 신규 8개 기능 어디에도 실주문 경로가 없어야 한다(읽기전용·제안·로컬 파일만).

## 0. 사전 준비 (Prereqs)

- [ ] **빌드/실행**: `dotnet build StockManager.sln -c Release -m:1` → `StockManager/bin/Release/net8.0-windows/MS2E.StockSuite.exe` 실행 (또는 VS에서 F5).
- [ ] **WebView2 런타임** 설치 확인 (Blazor 대시보드가 빈 흰 화면이면 미설치 의심).
- [ ] **데이터**: 포트폴리오/회고 기능 점검을 위해 **보유 종목 2~3개**(가능하면 KRX 6자리 + 미국 티커 섞어) + **매수/매도 거래 이력 몇 건** 입력.
- [ ] **저장 전략**: 토너먼트/신호 모니터에 출전자가 생기도록 `/forge` 또는 `/compiler`에서 **카트리지 1개 이상 서명**(없으면 토너먼트는 내장 벤치만, 신호는 "저장 전략 없음").
- [ ] **LLM(선택)**: AI 기능 점검 시 `/settings`에서 **Gemini API 키** 입력 또는 **Ollama 활성화**. 미설정 시 각 페이지가 "규칙 모드/미설정"으로 **결정론 부분만 동작**해야 함(핵심 점검 포인트).
- [ ] **네트워크**: 시세 조회(Naver/Yahoo)·환율(USDKRW)·LLM은 네트워크 필요. 오프라인이면 "조회 실패"가 **예외가 아니라 안내 메시지**로 떠야 함.

### 빠른 스모크 테스트 (5분)
- [ ] 좌측 내비에 `MS2-E · v3.65` 표시, 그룹별 신규 항목 보임(아래 각 그룹).
- [ ] 각 신규 페이지를 한 번씩 열어 **빈 화면/콘솔 예외 없이** 렌더되는지.
- [ ] 종목 하나 클릭(전역 SymbolContext) → 종목 인식 페이지들의 입력칸에 코드 자동 반영.

## 1. 🦢 블랙스완 시뮬레이터 — `/blackswan`  (리스크 시뮬 그룹)
- **전제**: 보유 주식 ≥1.
- [ ] 페이지 진입 시 현재 보유로 자동 1회 주입, **KPI(최종손익·최대낙폭·저점일·포트β)** + **붕괴 곡선 SVG** + **손실 기여 최악 종목 표** 렌더.
- [ ] 위기 시나리오 드롭다운(코로나/2008/2022/블랙먼데이) 변경 → 즉시 재계산.
- [ ] **베타 가정** 입력 변경(예 1.0→1.5) → 낙폭 더 깊어짐(β 스케일 반영).
- [ ] 보유 없을 때: "보유 종목이 없습니다" 안내(크래시 X).
- [ ] 곡선이 하락=레드, 저점 마커 표시.

## 2. 🌙 자율 야간 연구 루프 — `/research`  (AI & 저널 그룹)
- **전제**: 보유 주식 ≥1(각 18개월 일봉 조회 가능).
- [ ] "**지금 실행**" 클릭 → 수십 초 후 KPI(스캔/발굴/카트리지) + 발굴 표 + (정책 있으면)코파일럿 제안 렌더.
- [ ] 발굴 시 **자가서명 카트리지 생성** 안내(파일명) → `/cartridges`에 실제 파일 생성 확인.
- [ ] **인과 저널 적재**: 실행 후 `/intel/journal`에 "🌙 밤사이 연구 완료" 알림이 타임라인에 보임.
- [ ] **야간 자동 실행** 토글·시각·목표·텔레그램 설정이 저장/복원됨.
- [ ] 헤드라인·표에 "과거 OOS" vs "확률추정" 구분 표기(정직성).
- [ ] **게이팅**: 어떤 버튼도 실주문을 내지 않음(발굴·서명·제안만).

## 3. 🧱 LLM 전략 컴파일러 — `/compiler`  (전략 연구소 그룹)
- **전제**: 종목코드(백테스트용). AI 컴파일은 LLM 필요.
- [ ] 예시 칩 클릭 → 텍스트 입력 → "**⚙ 컴파일(규칙)**" → 스펙 설명 + KPI(수익·MDD·승률·매매·샤프) + 자본곡선 SVG.
- [ ] LLM 미설정 시 "**🤖 AI 컴파일**" 버튼 **비활성**(규칙 컴파일은 정상).
- [ ] LLM 설정 시 AI 컴파일 → 같은 결과 구조(검증 통과분만). 깨진 출력이면 규칙 폴백 안내.
- [ ] "**🧬 카트리지로 서명**" → `/cartridges`에 파일 생성. MA크로스면 "증명서 첨부" 안내.
- [ ] 종목 입력 전 컴파일 → "스펙 컴파일 성공, 종목 입력하면 백테스트" (진단 메시지가 "성공"에 덮이지 않음).

## 4. 🪞 회고 코치 — `/coach`  (AI & 저널 그룹)
- **전제**: **매수/매도 거래 이력**(닫힌 라운드트립 ≥1). 없으면 "거래 이력 없음".
- [ ] "**거래 회고 분석**" → KPI(닫힌거래·승률·손익비·평균보유·월매매) + 편향 카드 + 닫힌거래표.
- [ ] **반사실** "조기매도 기회손익(보유했다면)" 값 표시 — USD 종목 환산이 합리적(≈1380배 폭주 없음).
- [ ] 편향 카드(처분효과·손익비·과매매·추격·패닉·물타기)가 표본 충분할 때만 등장(소표본 오탐 없음).
- [ ] LLM 설정 시 "**🤖 AI 코칭**" → 결정론 수치 근거 서술. 미설정 시 버튼 비활성.
- [ ] **게이팅**: 사후 복기 정보만, 매매 지시 문구 없음.

## 5. 🩺 종합 건강검진 — `/health`  (포트폴리오 그룹)
- **전제**: 보유 주식 ≥1(분산 축은 시세 ≥2종목 필요).
- [ ] "**종합 검진 실행**" → 큰 점수 + 등급(A~F) + 4축 막대(분산·위기·미래·행동) + 권고 + 리스크기여표 + 최악위기 카드.
- [ ] **데이터 부족 축**은 회색 막대 + "데이터 부족" 배지(중립), 점수 칸 "—" — 실측처럼 색칠되지 않음.
- [ ] 시세 1종목만 잡히면 분산 축이 **거짓 고득점(~91) 아니라 중립(50)** 으로.
- [ ] 실측 축 2개 미만이면 등급 "**—**"(평가 불가).
- [ ] 다계좌 동일종목 보유 시 종목 수가 합산 반영(과소계상 없음).

## 6. 🏆 전략 토너먼트 — `/tournament`  (전략 연구소 그룹)
- **전제**: 종목코드. 저장 카트리지 있으면 출전 풍부(없어도 내장 벤치 5종).
- [ ] 종목 입력 → "**토너먼트 실행**" → 리그 순위표(순위·전략·출처·OOS평균±σ·강건점수·전구간·폴드).
- [ ] 1위 행 하이라이트. 유효 폴드 부족 출전은 Rank "—" + 사유 표시(숨기지 않음).
- [ ] 노트에 "카트리지 N개 → 전략 M개 + 내장 벤치 5개" (디코드 실패 시 "디코드 실패 K건" 공시).
- [ ] 캔들 부족 종목 → "캔들 부족" 안내.

## 7. 🤖 에이전트 워크벤치 — `/agent`  (AI & 저널 그룹)
- **전제**: 없음(규칙 모드 동작). 종목 기능은 종목코드.
- [ ] 예시 칩/입력 → Enter 또는 보내기 → 의도에 맞는 카드 응답:
  - [ ] "**포트폴리오 위기 시뮬**" → 블랙스완 최악 요약 + `/blackswan` 링크.
  - [ ] "**005930 미래 전망**" → 확률 미래 요약(기대·손실확률·P5/P95) + `/future` 링크.
  - [ ] "**5일선 20일선 골든크로스 매수 손절 8%**" → 컴파일된 스펙 설명 + `/compiler` 링크.
  - [ ] "**종합 건강검진**"/"**회고**"/"**도움말**" → 안내 + 딥링크.
- [ ] 영문 티커 인식: "the AAPL future" → **AAPL**(선행 the가 가리지 않음), 소문자 "buy gold" → 종목 없음.
- [ ] LLM 설정 시 "**💬 AI 설명**" → 결정론 요약 근거 서술. LLM 오류 시 ⚠️ 메시지가 **서술이 아니라 경고 스타일**.
- [ ] 딥링크 버튼 클릭 → 해당 페이지로 이동.

## 8. 📡 전략 신호 모니터 — `/signals`  (전략 연구소 그룹)
- **전제**: **저장 전략(카트리지) ≥1** + 종목코드.
- [ ] 종목 입력 → "**신호 평가**" → 전략별 현재 상태 핀(신규 진입/청산 신호/보유 중/관망) + 설명.
- [ ] 행동 필요(신규 진입·청산) 행이 상단 정렬.
- [ ] 최장 지표기간보다 캔들이 적은 전략 → "**관망(표본 부족·워밍업 미달)**" (시드값 가짜 신호 없음).
- [ ] **게이팅/정직성**: "전략 규칙 상태 정보이며 매매 지시·자동 주문이 아님" 문구 노출.
